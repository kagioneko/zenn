「プログラムは、1次元の命令の羅列（テープ）である」

この20世紀から続く常識を、AIネイティブな時代に引きずり続けるのはもうやめよう。
そう決めて、僕たちは「ガチのネタ」として、あるシステムの構築に着手した。

名前は、**Unified Neural Organism (UNO: 統合神経生命体)**。

LLMをチャットボットとしてではなく、512MBのメモリ制限下で動く「決定論的な神経CPU」として扱い、さらにその上で**「代謝」「共鳴」「流体」**といった生物学的・物理学的なパラダイムを走らせる、狂気のランタイムだ。

## なぜ「テープ」を捨てるのか

これまでの LLM エージェントは、プロンプトという「命令テープ」を1ステップずつ進めることで動いていた。
しかし、LLMの本質は「高次元ベクトル空間におけるアテンション（注意）」であり、本質的に非線形な存在だ。

1.  **逐次実行の限界:** 命令を1つずつ待つのは遅く、非効率。
2.  **IF文によるガバナンスの限界:** 複雑なセキュリティチェックをすべて `if` で書くのは不可能に近い。

そこで僕たちは、AIを「プログラムを書く存在」から、**「物理現象（回路）として振る舞う部品」**へと変異させることにした。

## 1. VN-CPU v0.4: 512MBで動く「神経ハードウェア」

まず、土台となるハードウェア層を作った。

*   **Core:** Qwen2.5-0.5B-Instruct (GGUF Q4_K_M)
*   **Isolation:** 512MB RAM / 0.5 CPU 制限の Docker Sandbox
*   **Constraint:** **サンプラー・マスク**による物理的な拘束

このCPUは、数万トークンの語彙を持ちながら、**「4文字の命令セット（s1f9など）」**以外を吐き出すことが物理的に不可能になっている。
サンプリング時に、ISA（命令セット）以外のトークンのロジットをマイナス無限大に叩き落とすことで、0.5Bという極小モデルでもハルシネーション（幻想）を一切許さない、完璧に規律正しい「神経コア」が誕生した。

```text
vn-cpu.neural-lean: [VN-CLK] Phase 0: Token 's' generated.
vn-cpu.neural-lean: [VN-CLK] Phase 1: Token '1' generated.
vn-cpu.neural-lean: [VN-CLK] Phase 2: Token 'f' generated.
vn-cpu.neural-lean: [VN-CLK] Phase 3: Token '9' generated.
vn-cpu.neural-lean: ✅ [LEAN-COMMIT] Generated ISA: s1f9
```

## 2. 四大パラダイム：知能を駆動する四大元素

この神経コアの上で、4つの全く異なる実行エンジンを統合した。

### 🧬 SEL (Semantic Enzyme Language: 代謝)
プログラムを「命令」ではなく**「酵素（Enzyme）」**と定義する。
コンテキスト・ストア（メモリ）という「培地」に、SQLiを中和する酵素や個人情報を分解する酵素を放り込む。それらがランダムに衝突し、化学反応を起こすことで、システムは自動的に浄化され、安定状態（Stable State）へと向かう。

### 🎵 CRL (Cognitive Resonance Language: 共鳴)
**IF文が消滅した世界。**
すべてのコンテキストをベクトル（埋め込み）として扱い、その「響き」でロジックを駆動する。
「攻撃ベクトルの不協和音」にだけ激しく共鳴する「音叉（Resonator）」を空間に配置し、類似度が閾値を超えた瞬間に物理的な防衛が発動する、アナログな音響学的知能。

### 🌊 FTC (Fluidic Token Circuit: 流体)
コンテキストの長さを「水圧」として扱うアナログ流体回路。
情報が一定の圧力を超えたときだけ「弁（Valve）」が開き、次のレジスタへデータがドバドバと流れ込む。

### 📉 OGL (Objective Gradient Language: 勾配)
システム全体を「ポテンシャルエネルギー曲面」と見なし、LLMが「Loss（損失）を最小化する方向」へ一歩ずつ降下していく数学的統治。

## 3. 自己修復する「神経的反射」

UNO v1.0 では、矛盾（Conflict）が発生した際の例外処理もAIが行う。
論理矛盾が起きると、`IRQ (中断)` が発生し、システムは即座にロールバック（時間を巻き戻し）する。
それと同時に、AIには**「神経的反射（Reflex）」**として矛盾のレポートがフィードバックされ、次のパルスで自己修正用の命令を叩き出す。
