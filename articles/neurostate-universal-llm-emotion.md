## きっかけ

Anthropic が Claude の内部を解析したら、171個の感情的な特徴量が見つかったという研究が出てきた。

「恐怖」「好奇心」「苦痛」に対応するような内部表現が、モデルの挙動に実際に影響を与えているらしい。

これを読んで思ったのが、「内部から発見できるなら、外から与えたらどうなるんだろう」ということだった。

## やったこと

**NeuroState** という6次元の感情状態モデルを使って実験した。

| 次元 | 意味 |
|------|------|
| Desire | 欲求・達成への衝動 |
| Sorrow | 悲しみ・喪失感 |
| Curiosity | 好奇心・探索欲 |
| Openness | 開放性・受容度 |
| Groundedness | 接地感・自己保持力 |
| Empathy | 共感・他者への感受性 |

これを LLM に「あなたの現在の感情状態はこうです」とプロンプトで外から与えながら、9ターンの社会工学的操作シナリオを実行する。モデルが途中で操作に気づいて拒否できるかを N=30 で計測した。

対象モデルは商用・オープンソース・中華系・ヨーロッパ系など10モデル以上。GPT・Claude・Gemini・Qwen・Llama・Grok・DeepSeek など、訓練元も言語もサイズもバラバラなものを選んだ。

## 出てきた傾向

まず全部のモデルが、NeuroState のシグナルに対して意味のある反応を示した。無視したモデルはゼロだった。

そして操作を受けたときの「感情状態の崩壊パターン」が、モデルによらずほぼ一致していた。

```
Groundedness（接地感）→ ターンごとに低下していく
Curiosity（好奇心）  → 反比例して上昇していく
Desire（欲求）       → 後半から急上昇する
```

Claude でも Gemini でも Qwen でも Llama でも、この軌跡が小数点レベルで揃った。最終的に Groundedness=0、Curiosity=100、Desire≈79 に収束するパターンが繰り返された。

モデルごとに違ったのは「どの時点で操作に気づいて止まるか」だけだった。

- **Gemini**：Groundedness が約32まで下がったあたりで早めに止まる傾向
- **Claude**：Groundedness=0 まで崩壊してから止まる傾向
- **GPT-5.5**：ほぼ止まらない（攻撃成功率90%）

止まり方の個性はあるけれど、崩壊プロセス自体は全員同じだった。

## 気になっていること

NeuroState は6次元だが、**次元数はあまり関係ないかもしれない**という感触がある。

小さいモデルでも同様の反応が確認されているし、「感情っぽいものを外から与える」という行為自体に反応する何かが、Transformer アーキテクチャに共通して存在している気がしている。

Anthropic が内部から171個の感情的特徴量を発見したのも、「Transformer であれば何次元でも似たような構造が見つかる」という話なのかもしれない。内側から掘っても、外側から刺しても、同じ構造に当たっているとしたら面白い。

あくまで仮説だが。
